# البدء السريع - الترجمة العربية للمبالغ
# Quick Start - Arabic Amount Translation

## ⚡ خطوات سريعة (3 دقائق)

### 1️⃣ تثبيت المكتبة المطلوبة

```bash
pip3 install num2words
```

### 2️⃣ إعادة تشغيل Odoo

```bash
sudo systemctl restart odoo
```

أو إذا كنت تشغل Odoo يدوياً:
```bash
# أوقف Odoo (Ctrl+C)
# ثم شغله مرة أخرى
./odoo-bin -c /path/to/odoo.conf
```

### 3️⃣ ترقية الموديول

1. افتح Odoo
2. اذهب إلى: **Apps**
3. ابحث عن: **Thamar Invoice Customization**
4. اضغط: **Upgrade**

### 4️⃣ تفعيل اللغة العربية

1. اذهب إلى: **Settings → Translations → Languages**
2. ابحث عن: **Arabic / العربية**
3. اضغط: **Activate**

### 5️⃣ تغيير لغة المستخدم

1. اذهب إلى: **Settings → Users & Companies → Users**
2. اختر المستخدم الحالي
3. في تبويب **Preferences**:
   - **Language**: اختر **العربية / Arabic**
4. احفظ

### 6️⃣ اختبار

1. اذهب إلى: **Accounting → Customers → Payments**
2. افتح أي دفعة موجودة أو أنشئ دفعة جديدة
3. اضغط: **Print → Custom Payment Receipt**
4. يجب أن ترى المبلغ بالعربية! ✅

---

## 🎯 مثال سريع

**المبلغ:** 1250.75 جنيه

**سيظهر:**
```
ألف و مائتان و خمسون جنيه و خمسة و سبعون قرش
```

## ❓ مشاكل شائعة

### المبلغ لا يظهر بالعربية؟

✅ **تأكد من:**
1. تثبيت `num2words`
2. إعادة تشغيل Odoo
3. ترقية الموديول
4. تفعيل اللغة العربية
5. تغيير لغة المستخدم إلى العربية

### ظهور خطأ عند الطباعة؟

✅ **جرب:**
```bash
# تحقق من تثبيت المكتبة
pip3 show num2words

# إذا لم تكن مثبتة
pip3 install num2words

# أعد تشغيل Odoo
sudo systemctl restart odoo
```
