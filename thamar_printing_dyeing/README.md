# موديول الطباعة والصباغة

موديول Odoo 19 لإدارة تشغيل مصنع طباعة وصباغة الأقمشة.

## الوظائف الرئيسية

- إنشاء خطة تشغيل ببيانات العميل والرسالة والخامة واللون والطباعة والصباغة والكميات المتوقعة.
- إدخال مراحل الخطة وترتيبها بالسحب والإفلات بدون دورة حالات أو اعتماد.
- إدخال بيانات كل مرحلة بصورة مستقلة، مع الوردية ورئيسها والماكينة والعامل وأوقات الدخول والخروج.
- قائمة مستقلة لكل مرحلة تحت قائمة «المراحل»، بالإضافة إلى شاشة تجمع كل المراحل.
- إدخال الوزن والأمتار الفعلية من مرحلة الإعداد وترحيلها آليًا إلى الخطة والمراحل التالية.
- تعديل مراحل التشغيل مباشرة من شاشة قائمة قابلة للتحرير، مع زر لفتح النموذج التفصيلي.
- السماح للمدير فقط بتغيير العميل أثناء المرحلة مع تسجيل التغيير في المتابعة.
- احتساب الزمن المستهلك وتكلفة المرحلة آليًا.
- تجميع مراحل من عدة خطط في تشغيلة ماكينة واحدة (مثل الجيت)، مع ترحيل بياناتها وتوزيع تكلفة التشغيلة حسب وزن كل خطة.
- ربط الماكينة بأكثر من مرحلة، مع تعريف حمولتها واحتساب تكلفة الساعة من المياه والكهرباء والغاز والتكاليف الأخرى.
- تحليل المراحل حسب المرحلة والماكينة والتاريخ والوزن والأمتار والتكلفة.
- فصل صلاحيات المستخدم عن مدير الإعدادات، مع دعم تعدد الشركات.

## أسلوب الإدخال الحالي

1. يعرّف المدير الألوان والرسومات وأنواع الطباعة والصباغة والماكينات.
2. ينشئ المستخدم الخطة ويضيف المراحل بالترتيب المطلوب.
3. تُدخل بيانات المرحلة ووقت الدخول والخروج مباشرة بدون حالات بدء أو انتهاء أو إلغاء.
4. في المراحل التي تسمح بالتجميع يمكن إنشاء تشغيلة ماكينة واختيار مراحل عدة خطط وإدخال بياناتها مرة واحدة.

الموديول يحتوي افتراضيًا على مراحل المصنع المذكورة، وست ماكينات جيت للمصبغة وست ماكينات رام مرتبطة بمراحل التجهيز وتثبيت الحرارة والتجهيز النهائي وإعداد الكاربون والكسترة والكومباكتور والكلندر والطباعة. الحمولات ومكونات التكلفة تُستكمل من شاشة الماكينات.
