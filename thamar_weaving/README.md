# موديول النسيج (Weaving & Knitting Manufacturing)

موديول Odoo لإدارة تشغيل مصانع النسيج بنوعيه: **النسيج الدائري (Circular Knitting)** و**النسيج المستطيل / المسطح (Looms Weaving)**، مع التتبع الدقيق للأتواب واللوطات (Lot / Serial Tracking) والربط التلقائي بموديول **الطباعة والصباغة** (`thamar_printing_dyeing`) وقائمة خاصة لإدارة الماكينات وتكاليف تشغيلها.

---

## 1. الفلسفة الصناعية ودورة البزنس (Business Architecture)

```
[ خيوط الغزل الخام + أرقام اللوطات ]
                 │
                 ▼
      [ أمر تشغيل النسيج ]
      ├── نسيج دائري (Circular)  --> سلندر، جيج، مغذيات، طول غرزة، ليكرا
      └── نسيج مستطيل (Looms)    --> مشط، كثافة سداء، كثافة لحمة، نوع الحدف
                 │
                 ▼
       [ ماكينات النسيج ] (حساب تكلفة الساعة: كهرباء + عمالة + صيانة)
                 │
                 ▼
    [ سجل الأتواب والتتبع باللوط ]
      ├── رقم الثوب + رقم اللوط (Lot No)
      ├── الوزن الصافي الفعلي (كجم) + الأمتار + GSM + العرض
      ├── تصنيف الجودة (درجة أولى / ثانية / هالك)
      └── طباعة بطاقة / استيكر الثوب بالباركود
                 │
                 ▼
    [ مزامنة المخزن: stock.lot ]
                 │
                 ▼
  [ التسليم لموديول الطباعة والصباغة ] ◄── (سحب اللوط مباشرة في أوامر الصباغة)
```

---

## 2. نوعا النسيج والفرق الفني في النظام

### أ) النسيج الدائري (Circular Knitting):
- **المنتجات**: أقمشة تريكو دائرية/أسطوانية (سنجل جيرسي، ريب، إنترلوك، ميلتون، بيكيه، إلخ).
- **المواصفات الفنية للماكينة**:
  - القطر بالبوصة (Diameter: 30", 32", 34", إلخ).
  - الجيج (Gauge / GG: عدد الإبر في البوصة مثل 24GG, 28GG, 32GG).
  - عدد المغذيات (Feeders: 72, 84, 96 مغذي).
  - سرعة الدوران (RPM).
- **مواصفات أمر التشغيل**:
  - طول الغرزة بالمليمتر (Stitch / Loop Length).
  - نسبة الليكرا / الإيلاستين المخططة (%).
  - الوزن المستهدف للمتر المربع (Target GSM) والعرض المستهدف (Target Width).

### ب) النسيج المستطيل / المسطح (Rectangular / Looms Weaving):
- **المنتجات**: أقمشة منسوجة مسطحة على الأنوال (بوبلين، جبردين، قماش ملايات، شاش، داكرون، تويل، إلخ).
- **المواصفات الفنية للماكينة (الأنوال)**:
  - عرض المشط الأقصى (Reed Width: 190, 220, 280, 340 سم).
  - نوع النول والحدف (أنوال رابير سهمي، قذف هوائي Air-jet، قذف مائي Water-jet، جاكار Jacquard، مقذوف Projectile).
  - السرعة بالرمية في الدقيقة (Picks Per Minute - PPM).
  - أقصى عدد لأطر الدرء (Shafts / Harnesses).
- **مواصفات أمر التشغيل**:
  - كثافة السداء (Warp Ends / cm).
  - كثافة اللحمة (Weft Picks / cm).
  - نمرة المشط وعرض المشط المشغول.
  - التركيب النسجي (سادة 1/1، مبرد 2/1، أطلس/ساتان، إلخ).

## 3. التتبع باللوط والتكامل مع الطباعة والصباغة (`thamar_printing_dyeing`)

1. **توليد اللوط لكل ثوب**:
   - كل ثوب يتم تنزيله من الماكينة ينشئ أو يربط تلقائياً بسجل `stock.lot` رسمي في نظام المخازن.
   - اللوط يحمل كامل بيانات النسيج: الوزن الصافي، الطول، وزن المتر المربع الفعلي (GSM)، العرض، درجة الجودة، رقم الماكينة، وأرقام لوطات خيوط الغزل الأصلية.
2. **سحب اللوط في موديول الطباعة والصباغة**:
   - موديول الطباعة والصباغة (`thamar_printing_dyeing`) يستخدم رقم اللوط (`message_number` أو اختيار اللوط) لبدء خطة وأمر تشغيل الصباغة.
   - من شاشة الثوب في النسيج، يوجد زر مباشر: **«تحويل لمصبغة / سحب اللوط للطباعة والصباغة»** يقوم تلقائياً بإنشاء أمر تشغيل صباغة محمل ببيانات القماش واللوط والوزن الصافي والأمتار دون أي إدخال يدوي مكرر.
   - شاشة لوطات المخازن تم توريثها (`stock.lot`) لتعرض تبويب «تتبع ومواصفات النسيج» بحيث تظهر التفاصيل الفنية لأي جهة تفحص اللوط.

---

## 4. قائمة الماكينات وحساب تكلفة التشغيل

- **منيو مخصص للماكينات**:
  - كل الماكينات (عرض كانبان ملون حسب الحالة، قائمة، ونموذج تفصيلي).
  - ماكينات النسيج الدائري.
  - ماكينات النسيج المستطيل (الأنوال).
  - سجل التوقفات والأعطال (Mechanical, Electrical, Yarn Break, Setup, Maintenance).
- **حساب تكلفة الساعة بدقة**:
  - تكلفة الكهرباء / ساعة + العمالة المباشرة / ساعة + قطع الغيار والصيانة / ساعة + تكاليف أخرى = **إجمالي قيمة الساعة التشغيلية**.
  - احتساب تكلفة الماكينة لكل أمر تشغيل بناءً على ساعات التشغيل الفعلية.
  - احتساب **تكلفة الكيلو جرام الصافي** (تكلفة الغزل + تكلفة الماكينة ÷ الوزن الصافي المنتج).

## 5. هيكل القوائم (Menus)

```
النسيج
├── أوامر التشغيل
│   ├── كل أوامر التشغيل
│   ├── نسيج دائري (Circular)
│   └── نسيج مستطيل (أنوال)
├── الأتواب واللوطات
│   ├── سجل الأتواب واللوطات
│   ├── أتواب النسيج الدائري
│   ├── أتواب النسيج المستطيل
│   └── لوطات الأقمشة بالمخازن
├── الماكينات
│   ├── كل الماكينات (Kanban & List)
│   ├── ماكينات النسيج الدائري
│   ├── ماكينات النسيج المستطيل (الأنوال)
│   └── سجل التوقفات والأعطال
└── الإعدادات
    └── أسباب التوقف والأعطال
```
