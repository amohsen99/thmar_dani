# Thamar Category Product Barcode

موديول مستقل لتوليد كود الصنف والباركود من شجرة فئات المنتجات في Odoo 19.

## طريقة العمل

- يضاف إلى كل فئة **جزء كود رقمي**.
- يجمع النظام أجزاء الأكواد من أعلى الشجرة إلى الفئة المختارة.
- الفئة النهائية يمكن أن تكون فئة بمسلسل تلقائي أو فئة بكود ثابت.
- عند إنشاء Variant جديد يضع النظام نفس الرقم في **Internal Reference** و**Barcode**.
- يحتفظ كل Variant بمسلسله الخاص، ولذلك يمكن استخدام اللون أو الرسمة كـVariants بدون تكرار الباركود.
- بعد استخدام الفئة في توليد صنف، يمنع النظام تغيير بنية الكود لحماية الأكواد الموجودة.

## أمثلة البيانات المبدئية

| الفئة | تركيب الكود | أول كود |
|---|---:|---:|
| غزل بوليستر | `01 + 01 + 0001` | `01010001` |
| غزل قطن | `01 + 02 + 0001` | `01020001` |
| خام مستطيل بوليستر | `2 + 1 + 1 + 001` | `211001` |
| خام دائري بوليستر | `2 + 2 + 1 + 0001` | `2210001` |
| كيماويات | `4 + 0001` | `40001` |
| قطع غيار | `5 + 0001` | `50001` |
| متنوعات | `6 + 0001` | `60001` |
| فضلات الطباعة | كود ثابت | `3555555` |
| فضلات الصباغة | كود ثابت | `3666666` |

الموديول يعتمد على `product` القياسي فقط، ولا يعتمد على `thamar_product_barcode` أو أي موديول مخصص آخر.

الموديول القديم `thamar_product_barcode` يحتوي هو أيضًا على مولد باركود عند إنشاء الصنف. لذلك عند الانتقال للنظام الجديد يجب تشغيل مولد واحد فقط، ثم تثبيت هذا الموديول باعتباره البديل المستقل.
